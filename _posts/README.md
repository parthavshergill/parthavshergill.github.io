# Blog Posts

Add your blog posts here. Each post should follow this format:

## File naming
`YYYY-MM-DD-title-with-hyphens.md`

Example: `2025-01-15-my-first-post.md`

## Front matter template

```markdown
---
title: "Your Post Title"
date: YYYY-MM-DD
permalink: /posts/YYYY/MM/title/
tags:
  - tag1
  - tag2
excerpt: "A brief summary of your post that appears in previews"
---

Your post content here...
```

## Tips
- The `excerpt` will be shown on the homepage preview
- Tags help organize your posts
- Use markdown for formatting
- The permalink structure helps keep URLs clean
